# 🔭 Atelier Super-Résolution : Astronomie & IA

Bienvenue à l'**Atelier de Super-Résolution** ! Ce dépôt contient le matériel nécessaire pour une session pratique explorant l'intersection entre l'astronomie observationnelle traditionnelle et l'intelligence artificielle moderne.

Nous explorons comment transformer des données brutes et bruitées de télescope en images claires et détaillées en utilisant deux approches distinctes : le pipeline traditionnel d'astrophotographie et les modèles de diffusion.
